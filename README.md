# Kart Amigos

Carreras de karts en 3D para jugar con amigos desde el navegador: https://11diegonavarro-code.github.io/kart-amigos/

- Crea una sala online y comparte el enlace; los demás solo tienen que abrirlo y pulsar «Unirse».
- Conexión directa entre navegadores (WebRTC) con respaldo automático por servidores MQTT públicos si la red la bloquea.
- Gráficos: Ultra, Altos o Rendimiento, con resolución dinámica para mantener la fluidez.

## Créditos

- Texturas y cielo HDRI: [Poly Haven](https://polyhaven.com) (CC0) — `asphalt_track`, `leafy_grass`, `rocky_terrain_02`, `aerial_rocks_02`, `kloofendal_48d_partly_cloudy_puresky`.
- Motor 3D: [three.js](https://threejs.org) (MIT). Red: [PeerJS](https://peerjs.com) (MIT) y [MQTT.js](https://github.com/mqttjs/MQTT.js) (MIT).
